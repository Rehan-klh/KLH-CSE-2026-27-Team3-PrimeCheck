Abstract

PrimeForge is a web-based project for checking and generating large prime numbers. The main algorithm used is the Miller-Rabin Primality Test, which is suitable for testing very large integers with high probability. Our system is planned to support numbers up to 1024 bits and display the result, confidence level and execution time. Along with prime checking, we are working towards adding prime generation, performance comparison and parallel processing. The project is being developed as part of our DSA-3 course.


Introduction

Prime numbers are important in many areas of computer science, especially cryptography. Checking large numbers for primality using simple methods becomes slow as the size of the number increases.

In this project, we are using the Miller-Rabin Primality Test to make large prime checking more efficient. The final system will provide a simple web interface where users can enter large numbers and view the results.


Problem Statement

Testing very large numbers for primality using traditional methods can take a lot of time. We need an efficient method that can work with large integers and provide a reliable result. PrimeForge focuses on solving this problem using the Miller-Rabin Primality Test.


Objectives

1. Implement the Miller-Rabin Primality Test in Java.
2. Support large integers up to 1024 bits.

4. Show the confidence level and execution time.

Literature Survey

Miller-Rabin is a commonly used probabilistic approach for primality testing. Miller introduced the original primality test and Rabin developed the probabilistic version. The method is useful for large numbers because it can give a result much faster than checking every possible factor.

Our project uses this approach as the main algorithm and focuses on implementing it and testing its performance with large integers.


Methodology

The project is being developed in stages. We first set up the Java project and work on the Miller-Rabin implementation. The algorithm takes a large integer and performs multiple randomized tests using different bases.

The system will record the number of iterations, confidence level and execution time. After the basic testing part is completed, we will work on prime generation, benchmarking and parallel testing before connecting everything to the web interface.
